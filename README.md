# PayTrack Frontend

Mobile-first React web app for tracking subscriptions, renewal dates, payment methods, and spending insights.

## Stack

- Vite 6
- React
- React Router
- Tailwind CSS
- i18next
- Recharts
- lucide-react

## Local Setup

```bash
npm install
cp .env.example .env
npm run dev
```

The app runs on `http://localhost:5173`.
